# plusコマンド
![test](https://github.com/harkingjoe/robosys2026/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ数字を足す。

使用のための簡単なコマンド: $ echo <足したい値を列挙> | tr ' ' '\n' | ./plus

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
